# Natty Library

React library management system for BIWA2110.

## Login
Login code: NATTY123

## Run
1. Open Command Prompt.
2. Go to this folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the Local URL shown by Vite.

Example:
`cd Downloads\Natty_library`
`npm install`
`npm run dev`

The project uses React, React Router, React hooks, CSS and browser Local Storage.
